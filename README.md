# Plateforme de Gestion de Commandes B2B
Projet 1 du stage Full Stack 1 mois (Arrowstack).
Application web multi-rôles pour un distributeur : catalogue produits,
panier, commandes, factures, gestion du stock et journal d'audit.
## Stack technique
React (Vite) · Node.js/Express · Prisma · PostgreSQL · JWT · Docker
